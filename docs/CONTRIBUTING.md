# 🤝 Contributing to Claude OpenRouter

We welcome contributions from the community!

### How to Contribute
1. Fork the repository.
2. Create your feature branch (`git checkout -b feature/amazing-feature`).
3. Commit your changes (`git commit -m 'feat: add support for dynamic rate tracking'`).
4. Push to the branch (`git push origin feature/amazing-feature`).
5. Open a Pull Request.

### Development Setup
```bash
git clone https://github.com/vikrant-project/claude-openrouter.git
cd public
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python -m src.bridge
```

Feel free to open issues for feature requests or new free model discoveries!
